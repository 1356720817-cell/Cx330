# creating-general-video-covers

A generic, shareable video-cover creation skill.

## What it does

It standardizes the workflow for video thumbnail/cover creation across platforms and industries:

Title → Person decision → 3 visual styles → aesthetic reduction → final plan → dual-ratio generation → inspection.

## Mandatory delivery

Every confirmed generation must output:

- 3:4 vertical
- 4:3 horizontal

Both must be independently composed and checked.

## Privacy / portability

This package contains no user-specific, brand-specific, account-specific, or project-specific data.
