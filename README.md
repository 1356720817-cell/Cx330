# creating-general-video-covers

**自媒体视频封面制作 Skill｜A video-cover creation skill for content creators**

> 视频脚本 / 视频标题 / 参考封面（会先确认新主题）→ 原创封面方案 → Taste 审美审核 → 3:4 + 4:3 双比例成图

`creating-general-video-covers` 是一套面向自媒体创作者的视频封面制作工作流。它可以从视频脚本或视频标题出发，也可以先接收参考封面并补充确认新视频主题；随后提炼封面钩子、设计原创视觉方向，并在生成前进行基于 Taste Skill 的审美审核，最终交付独立构图的竖版与横版封面。

它不绑定任何固定账号、人物、行业或品牌，可用于抖音、小红书、视频号、YouTube 等平台，以及知识、旅游、商业、汽车、美食、生活方式、教育等内容方向。

## 中文说明

### 这个 Skill 可以解决什么问题？

自媒体封面制作经常卡在“知道视频讲什么，但不知道封面该怎么表达”。这个 Skill 主要解决：

- **只有脚本，没有封面思路**：从脚本中提取核心看点、冲突、利益点或悬念，转化为适合封面的主标题与副标题。
- **只有标题，不知道如何视觉化**：围绕标题设计主体、场景、构图、色彩和文字层级。
- **有参考封面，但不想照搬**：分析参考图的构图、信息层级、主体比例、字体行为、配色关系、留白和视觉节奏，再结合你的内容重新设计。
- **标题太长、信息太多**：默认将封面控制为“1 个主标题 + 1 个副标题”，避免把封面做成脚本摘要或信息海报。
- **风格方案看起来都一样**：先提供 3 个真正不同的视觉方向，不接受只换颜色的伪多方案。
- **画面装饰过多、AI 味明显**：通过 Taste 审美审核减少无意义标签、图标、描边、发光、速度线和模板化元素。
- **横竖版只是简单裁切**：分别为 `3:4` 竖版与 `4:3` 横版重新构图，保留统一主题但适配不同画幅。
- **成图后无人检查**：分别检查文字、人物、主体结构、构图安全区、缩略图可读性与整体审美。

### 核心亮点

| 亮点 | 带来的价值 |
|---|---|
| 脚本、标题或参考封面均可启动对话 | 不要求用户先整理成完整设计需求；只有参考图时会继续确认新视频主题 |
| 先提炼标题，再设计画面 | 让视觉围绕内容钩子服务，避免“画面很好看但主题不清楚” |
| 参考设计逻辑，而不是机械复制 | 保留参考封面的有效方法，同时生成符合自己内容的原创方案 |
| 3 个明显不同的视觉方向 | 在生成前先做选择，减少盲目抽卡和重复返工 |
| 内置基于 Taste Skill 的审美审核 | 强化焦点、层级、留白与一致性，减少过度装饰和明显的 AI 模板感 |
| 双比例独立构图 | 同时满足移动信息流竖版和横版展示需求 |
| 双图分别检查 | 降低错字、乱码、人物变形、主体结构错误和裁切问题 |

### Taste 审美审核做什么？

在用户选定视觉方向后、正式生成之前，工作流会进行一次基于 Taste Skill 方法的审美减法与预检。它关注的不是“再加一点装饰”，而是判断什么应该保留、什么应该删除。

审核重点包括：

- 封面的第一视觉焦点是否明确；
- 信息层级是否保持“主标题 > 核心主体 > 副标题 > 辅助元素”；
- 文字密度是否适合手机信息流快速阅读；
- 留白是否足够，主体和标题是否拥有呼吸空间；
- 字体、颜色、阴影、描边和特效是否过量；
- 是否存在常见的 AI 海报感、模板感或无意义装饰；
- 人物、产品、车辆、食物或场景是否真实可信；
- 画面是否真正服务于内容目标和目标受众。

Taste 审核不能保证点击率，但可以降低“信息堆满、层级混乱、装饰过度、看起来像通用 AI 模板”等常见问题。

这里的“Taste 审核”是一套内置于工作流的审美检查清单，不是第三方认证、独立评分服务或点击率预测系统。

| 参考封面 | 可选 | 用于分析构图、层级、配色、字体、留白和节奏，不会机械照搬 |
| 发布平台 | 可选 | 如抖音、小红书、视频号、YouTube |
| 人物参考图 | 可选 | 如需要真人出镜，用于保持身份相关特征；是否使用仍需确认 |
| 产品或主体图片 | 可选 | 产品、车辆、食物、设备、景点等核心视觉素材 |
| 品牌素材或 Logo | 可选 | 只有用户明确要求时才会加入 |
| 视觉偏好 | 可选 | 如纪实、综艺、高级、极简、电影感、编辑感等 |
| 明确限制 | 可选 | 禁用词、不能出现的元素、品牌规范、事实准确性要求等 |

### 它会如何工作？

1. **理解内容与素材**：确认平台、主题、脚本、参考图、人物、产品、品牌素材和限制。
2. **先生成标题方案**：给出主标题与副标题选项，用户确认后再进入视觉设计。
3. **确认是否使用人物**：有真人图时确认是否出镜；没有真人图时提供明确选择。
4. **提出 3 个视觉方向**：在构图、主体比例、字体、色彩、视角、情绪或留白等方面形成真实差异。
5. **执行 Taste 审美审核**：做信息减法，确定视觉焦点，控制文字、颜色、特效与 AI 模板感。
6. **提交生成前方案**：明确标题、人物、核心主体、构图、视觉系统以及不会出现的元素。
7. **生成两种比例**：自动生成 `3:4` 竖版和 `4:3` 横版，不需要用户再次催促第二张。
8. **分别检查两张成图**：检查文字、人物、主体、构图、可读性与审美；发现明显问题时继续修正。

只有标题、人物、视觉方向或最终生成等真实决策需要用户确认。工具耗时、单张图片完成或中间步骤结束不会被当作暂停理由。

### 最终会输出什么？

| 阶段 | 输出内容 |
|---|---|
| 标题阶段 | 多组“主标题 + 副标题”候选方案 |
| 人物阶段 | 是否使用人物及人物类型的明确决定 |
| 风格阶段 | 3 个具有不同构图与视觉语言的设计方向 |
| 审美阶段 | Taste 审核后的减法结果与生成前最终方案 |
| 成图阶段 | 1 张 `3:4` 竖版封面 + 1 张 `4:3` 横版封面 |
| 检查阶段 | 对两张图分别完成文字、人物、主体、构图和审美检查；必要时修正 |

图片格式、像素分辨率、下载方式和可自动修正的次数由实际运行环境与图像生成工具决定。本工作流的固定交付要求是两种画幅都生成、分别构图并分别检查；如果图像工具不可用或生成失败，应明确报告当前缺失的交付项，而不能把单张图片视为完成。

### 参考封面会如何处理？

参考封面用于提取可复用的设计逻辑，例如：

- 构图关系；
- 信息层级；
- 主体大小与位置；
- 字体行为；
- 配色关系；
- 留白方式；
- 视觉节奏。

这些规律会结合新的视频内容重新设计。Skill 不以像素级复刻、品牌冒充或机械复制为目标，但它不提供版权结论、商标审查或自动相似度评分；公开发布前仍应由使用者检查是否过度接近参考作品。

### 双比例交付规则

| 比例 | 主要用途 | 构图特点 |
|---|---|---|
| `3:4` 竖版 | 手机信息流、竖屏内容平台 | 强纵向层级、主体集中、移动端小图可读 |
| `4:3` 横版 | 横向缩略图、栏目展示、部分长视频场景 | 强左右关系、更宽环境信息、横向平衡 |

两张封面会保持主标题、副标题、核心主体、视觉风格、色彩系统和人物设定一致，但不会把其中一张简单裁切成另一种比例。

默认横版固定为 `4:3`，不等同于 YouTube 常用的 `16:9` 缩略图。如果任务必须交付 `16:9`，需要在使用前扩展或修改本 Skill 的比例规则；当前默认交付不包含 `16:9`。

### 使用边界

- 本 Skill 提升的是封面制作流程、视觉判断和交付完整度，不承诺具体点击率或播放量。
- 涉及法律、医疗、金融、统计、政策、时效性或官方结论时，应先确认核心事实，再制作绝对化标题。
- 不会自动沿用其他任务中的人物、账号、品牌、Logo、行业规则或历史视觉体系。
- 用户当前任务中明确提供的信息优先，未获批准的 Logo、标签、数据和额外文案不会自动加入。

## English

### What is this skill?

`creating-general-video-covers` is a reusable video-cover and thumbnail workflow for content creators. It can start from a video script or working title, or begin with a reference cover and then confirm the new video's topic. It extracts the strongest content hook, develops original visual directions, applies a Taste-inspired aesthetic review before generation, and delivers independently composed vertical and horizontal covers.

It is not tied to a specific account, person, industry, brand, or visual identity. It can be used for Douyin, Xiaohongshu, WeChat Channels, YouTube, and other video platforms across education, travel, food, automotive, business, lifestyle, reviews, and more.

### What problems does it solve?

- **You have a script but no cover idea**: It extracts the core benefit, conflict, curiosity gap, or key promise and turns it into a main title and subtitle.
- **You have a title but do not know how to visualize it**: It builds the subject, scene, composition, palette, and typographic hierarchy around the title.
- **You have a reference cover but do not want to copy it**: It studies the composition, hierarchy, subject scale, typography, color relationships, negative space, and rhythm, then redesigns them for your content.
- **Your cover has too much text**: It defaults to one main title and one subtitle instead of turning the cover into a script summary or infographic.
- **Every proposed style looks the same**: It presents three genuinely different visual directions before image generation; color swaps alone do not count.
- **The image feels overdecorated or obviously AI-generated**: A Taste-inspired review removes unnecessary labels, icons, outlines, glows, speed lines, and template-like effects.
- **The horizontal version is only a crop of the vertical one**: It recomposes `3:4` and `4:3` layouts independently while preserving one visual system.
- **Generated images are delivered without review**: It checks text, people, subject structure, safe areas, thumbnail readability, and visual finish in both versions.

### Key advantages

| Advantage | Value |
|---|---|
| Script, title, or reference cover can start the conversation | You do not need a complete brief; a reference-only start is followed by confirmation of the new topic |
| Title decisions happen before visual execution | The design serves the content hook instead of hiding it |
| Reference logic is studied without mechanical copying | Useful visual principles are retained while the result remains specific to your content |
| Three meaningfully different directions | You choose a concept before spending time on repeated generations |
| Taste-inspired aesthetic review | Improves focus, hierarchy, negative space, and coherence while reducing generic AI patterns |
| Independent dual-ratio composition | Supports vertical mobile feeds and horizontal thumbnail contexts |
| Separate inspection for both images | Reduces typos, garbled text, distorted anatomy, structural errors, and cropping issues |

### What does the Taste-inspired review do?

After a visual direction is selected and before generation begins, the workflow performs an aesthetic reduction and pre-flight review based on Taste Skill principles. Its job is not to add more decoration; it decides what deserves attention and what should be removed.

It reviews:

- whether the first focal point is obvious;
- whether the hierarchy follows “main title > core subject > subtitle > supporting elements”;
- whether text density works in a fast-moving mobile feed;
- whether the title and subject have enough breathing room;
- whether fonts, colors, shadows, outlines, and effects are excessive;
- whether the image shows generic AI-poster habits or meaningless decoration;
- whether people, products, vehicles, food, and environments look believable;
- whether the visual language fits the content goal and audience.

This review cannot guarantee click-through rate, but it reduces common problems such as clutter, weak hierarchy, excessive styling, and generic AI-template aesthetics.

“Taste-inspired review” means a built-in aesthetic checklist within this workflow. It is not a third-party certification, an independent scoring service, or a click-through-rate prediction system.

### Where can it be used?

- Covers and thumbnails for Douyin, Xiaohongshu, WeChat Channels, YouTube, and similar platforms;
- short-form videos, long-form videos, series, educational explainers, interviews, and presenter-led content;
- travel, food, automotive, business, education, reviews, lifestyle, and other creator categories;
- tasks with a reference cover where the visual logic should be adapted rather than copied;
- text-led, person-led, product-led, or scene-led cover designs.

### What inputs can you provide?

The minimum input has two stages:

- **To start the conversation**: provide any one of a video topic/title, a video script, or a reference cover.
- **Before title and visual design begin**: confirm the new video's topic/title or provide a script from which the topic can be extracted. A reference cover can start the conversation, but it does not replace the new video's content information.

You can then add any of the following materials:

| Input | Required? | Notes |
|---|---:|---|
| Video topic or title | Required when no script is provided | A one-line topic, working title, or final title is enough |
| Video script | Required when no topic/title is provided | A full script, voice-over, outline, or key excerpt can be used |
| Reference cover | Optional | Used to study composition, hierarchy, palette, typography, spacing, and rhythm—not to copy mechanically |
| Target platform | Optional | Douyin, Xiaohongshu, WeChat Channels, YouTube, etc. |
| Person reference image | Optional | Used to preserve identity-relevant traits if the person is approved for the cover |
| Product or subject image | Optional | Products, vehicles, food, devices, landmarks, or other core visual material |
| Brand assets or logo | Optional | Included only when explicitly requested |
| Visual preference | Optional | Documentary, entertainment, premium, minimal, cinematic, editorial, and so on |
| Constraints | Optional | Forbidden words, excluded elements, brand rules, factual requirements, and other limits |

If no reference cover is provided, the skill proposes original design directions. If you provide only a reference cover, it first confirms the new video's topic or title before adapting the reference's design logic. If no person image is provided, it asks you to choose between no person, a generic non-user person, or waiting for a real reference image. It does not import people from unrelated tasks.

### How does the workflow run?

1. **Understand the content and assets**: Identify the platform, topic, script, references, people, products, brand assets, and constraints.
2. **Generate title options first**: Propose main-title and subtitle combinations before any image is generated.
3. **Confirm person usage**: Decide whether to use a real reference person, a generic person, or no person.
4. **Present three visual directions**: Create meaningful differences in composition, scale, typography, palette, viewpoint, mood, or negative space.
5. **Apply the Taste-inspired review**: Reduce noise, establish one focal point, and control text, colors, effects, and generic AI patterns.
6. **Present the final pre-generation plan**: Lock the titles, person, core subject, composition, visual system, and explicit exclusions.
7. **Generate both ratios**: Produce `3:4` vertical and `4:3` horizontal versions automatically.
8. **Inspect both outputs separately**: Check text, people, subjects, composition, readability, and aesthetics; correct visible problems when needed.

The workflow pauses only for real decisions such as title selection, person usage, visual direction, and final generation confirmation. Tool latency or completion of only one image is not treated as a reason to stop.

|---|---|

| Person stage | A clear decision about person usage and person type |
| Style stage | Three directions with distinct composition and visual language |
| Aesthetic stage | Taste-reviewed reductions and a final pre-generation plan |
| Generation stage | One `3:4` vertical cover and one `4:3` horizontal cover |
| Inspection stage | Separate text, person, subject, composition, and aesthetic checks, with corrections when necessary |

Image format, pixel resolution, download method, and the number of automatic correction attempts depend on the runtime and image-generation tool. The fixed workflow requirement is to generate, independently compose, and separately inspect both aspect ratios. If the image tool is unavailable or generation fails, the missing deliverable must be reported explicitly; one image alone is not treated as completion.

### How is a reference cover used?

A reference cover is analyzed for reusable design logic such as:

- composition;
- information hierarchy;
- subject size and placement;
- typographic behavior;
- color relationships;
- negative space;
- visual rhythm.

Those principles are redesigned around the new video content. The skill is not intended for pixel-level replication, brand impersonation, or mechanical copying, but it does not provide a legal copyright opinion, trademark review, or automated similarity score. Users should still check that a public result is not excessively similar to the reference.

### Dual-ratio delivery

| Ratio | Typical use | Composition priority |
|---|---|---|
| `3:4` vertical | Mobile feeds and vertical-first video platforms | Strong vertical hierarchy, concentrated subject placement, small-screen readability |
| `4:3` horizontal | Horizontal thumbnails, series displays, and some long-form contexts | Left-right relationships, wider context, and horizontal balance |

Both covers preserve the main title, subtitle, core subject, visual style, color system, and approved person settings. One version is never treated as a simple crop of the other.

The default horizontal ratio is fixed at `4:3`; it is not the same as the `16:9` format commonly used for YouTube thumbnails. If a task requires `16:9`, the Skill's ratio rules must be extended or modified before use. `16:9` is not part of the current default delivery.

### Scope and limits

- The skill improves the cover-making process, visual judgment, and delivery completeness; it does not promise a specific click-through rate or view count.
- Legal, medical, financial, statistical, policy, time-sensitive, or official claims should be verified before being converted into absolute cover headlines.
- It does not automatically reuse people, accounts, brands, logos, industry rules, or visual systems from unrelated tasks.
- Current-task instructions take priority, and unapproved logos, badges, data, or extra copy are not added automatically.
